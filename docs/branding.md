# AtriOS branding — instructions for AI agents

Canonical mark: **blue→purple concentric arcs with orange accent dot**
(author's SVG: [`docs/assets/atrios-mark.svg`](assets/atrios-mark.svg)).
This document is the single source of truth for reproducing and
modifying every branded asset. Follow it exactly; the design was
approved by the maintainer.

## Regeneration (exact commands)

```bash
cd <repo root>
# 1. mark
python3 tools/branding/raster.py docs/assets/atrios-mark.png --size 1600
# 2. wallpaper + boot splash
bash tools/branding/wallpaper.sh docs/assets/atrios-mark.png /tmp/branding
cp /tmp/branding/atrios-logo.png docs/assets/atrios-logo.png
cp /tmp/branding/atrios-station-720p.bmp packages/blobs/splash/atrios-station-720p.bmp
# 3. plymouth mark
magick docs/assets/atrios-mark.png -resize 512x512 \
       packages/plymouth-theme-atrios/atrios-logo.png
```

Requires: ImageMagick (magick), fontconfig with DejaVu Sans.
Pure-python rasterizer — no PIL/numpy needed.

## Design rules — DO NOT BREAK

1. **Layer order = painter's model, orange dot LAST.** The accent dot
   sits on the outer-arc path; any layer drawn after it recolors it.
   In raster.py the comparison is strict (`a > alpha`), so the last
   opaque layer wins. Never move the dot earlier in the stack.
2. **Dot color is always `#F59E0B`**, radius 11 (viewbox units),
   center (291.77, 68.94) — exactly at the −55° gap of the outer arc.
3. Gradient endpoints `#2563EB → #7C3AED` along the main diagonal
   (top-left blue, bottom-right purple).
4. Geometry (viewbox 400): outer arc r=160 stroke=14, gap centered
   at −55° (~40° wide); mid ring r=112 stroke=12; core disc r=58.
5. Wordmark: DejaVu Sans Bold, `#f5f8fc` on dark backgrounds;
   subtitle `#7c8ba1`, letter-spaced.

## Design variants (proposals, NOT in repo)

`tools/branding/variants.py` renders four alternates of the same mark
(LED-segmented ring, dual-gap orbit, outline core, minimal). The
segmented variant ("v1-ledring") is the maintainer's favorite and is
**pending approval** — proposal PNGs live on the maintainer's Windows
desktop (`AtriOS-вариант-*.png`, `AtriOS-logo-new.png`). The repo
stays on the solid-arc design until an explicit decision.

If the segmented variant is approved:
1. Add `seg24` layer support to raster.py (copy from variants.py —
   24 segments, each ≤68% of the 15° slot, dot drawn last).
2. Regenerate everything with the commands above.
3. Update this document.

## Gotchas learned the hard way

- ImageMagick MSVG cannot render gradient strokes/fills of this SVG —
  do not `magick logo.svg logo.png`; use the rasterizer.
- ImageMagick security policy blocks `-draw "@file.mvg"` — pass draw
  commands inline.
- `CopyOpacity` chains: dest needs `-alpha set` first, and nested
  composites must go through intermediate files (see wallpaper.sh).
- sysfs `--watch-gpio`-style per-line requests: a whole-chip request
  fails EBUSY if any line is claimed (relevant for GPIO debugging, not
  branding — kept here because it cost us a rewrite once).
