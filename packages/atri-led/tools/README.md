# Голосовая Биометрия и Распознавание "Свой / Чужой" (Yandex Station Max)

Оригинальный алгоритмический стек биометрии голоса, портированный из прошивки Яндекс Станции Макс (Quasar `bio_lingware`).

---

## 🌟 Возможности системы

1. **Нейросетевая биометрия ECAPA-TDNN (512-d)**:
   - Модели `body.tflite` (13 МБ) и `head.tflite` (1.3 МБ).
   - 80-полосный мел-фильтрбанк по спецификации Kaldi (`features_config.json`, 16-бит PCM масштаб `[-32768, 32767]`, преэмфазис 0.97, удаление DC-смещения).

2. **Акустический паспорт голоса владельца**:
   - Автокорреляционный трекер частоты основного тона голосовых связок ($F_0$) в диапазоне 60–650 Гц.
   - Определение тембра (бас, баритон, тенор, альт, сопрано) и спектрального центроида.

3. **Поддержка пения и напеваний**:
   - Определение растянутых музыкальных гласных (`max_consec_voiced >= 16`) и стабильности тона мелодии.
   - Адаптивный порог допуска владельца при пении (**65%**) либо отдельный эталон напева (`sing_emb`).

4. **Физико-акустический фильтр кашля и покашливаний**:
   - Двухуровневый детектор горлового трения (`crest >= 2.8`, всплеск 80–650 мс, `centroid >= 650` Гц, отсутствие гармоник связок) + сравнение с вектором кашля.
   - Автоматически помечает кашель как `🟠 ✖ КАШЕЛЬ / ПОКАШЛИВАНИЕ ВЛАДЕЛЬЦА (ИГНОРИРУЕТСЯ)`.

5. **Графический интерфейс (GUI)**:
   - Интерактивный мастер калибровки (полная 5 этапов, быстрая 3 этапа, либо точечная запись напева / кашля в 1 клик).
   - Мониторинг микрофона в реальном времени с индикатором громкости (VU-meter), осциллограммой, шкалой соответствия и журналом.
   - Тестирование произвольных WAV-файлов.

---

## 🚀 Запуск

### Установка зависимостей
```bash
pip install -r requirements.txt
```

### Запуск графического интерфейса
```bash
python voice_biometrics_gui.py
```

### Фоновый консольный демон
```bash
python realtime_voice_listener.py
```

### Тестирование WAV файлов через консоль
```bash
python voice_biometrics_demo.py test_audio.wav
```

## 📂 Структура файлов

- `voice_biometrics_gui.py` — Главное оконное приложение Tkinter.
- `realtime_voice_listener.py` — Консольный фоновый слушатель микрофона.
- `voice_biometrics_demo.py` — Утилита пакетной обработки и верификации аудио.
- `owner_profile.json` — Профиль владельца (паспорт, центроид, пение, кашель).
- `models/` — Нейросетевые модели TFLite (`body.tflite`, `head.tflite`, `features_config.json`).
